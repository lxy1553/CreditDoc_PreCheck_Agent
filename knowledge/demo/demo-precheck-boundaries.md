# 模拟制度：贷前材料预审辅助边界

> **虚构演示数据，仅用于验证检索、引用和人工复核流程，不代表任何机构的真实制度或监管要求。**

## 适用范围

本模拟规则仅适用于 `DEMO_ONLY` 机构的 `DEMO_PERSONAL_BUSINESS_LOAN` 演示产品。

## Agent 的工作范围

Agent 可以读取申请表和证明材料，输出可能缺失的材料、字段差异、证据位置和建议核实项。字段差异应同时列出两侧材料中的识别值和来源位置，供审核员查看。

Agent 不裁定材料真伪、不作授信审批、不自动要求客户补件、不自动退回申请，也不阻止申请进入审批。预审结论由审核员复核和确认。

## 失败处理

当材料无法可靠识别、规则检索不到有效依据或 Agent 不可用时，应标记需要人工处理，并保留原始材料查看入口。主申请流程继续流转。
