# Synthetic demonstration corpus

**All rules and checklist items in this folder are fictional examples created only to demonstrate ingestion and retrieval. They are not a bank policy, legal interpretation, or production checklist. Do not use them to review real applications.**

The demo manifest uses the isolated institution ID `DEMO_ONLY` and product line `DEMO_PERSONAL_BUSINESS_LOAN`. The importer requires an explicit `--allow-demo` flag for this corpus. Keep these materials separate from production knowledge sources.
