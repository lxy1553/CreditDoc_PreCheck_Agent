# Approved knowledge sources

Put only institution-approved, currently authorized policy and precheck guidance documents here. The initial importer accepts UTF-8 Markdown (`.md`) and plain text (`.txt`) only. Applicant applications, identity documents, income proofs, and other case-specific materials must not be placed in this shared knowledge directory.

Register every source in `config/manifest.json` with its document ID, version, approval status, effective period, institution, and product-line scope. The example manifest is a template only; replace every placeholder before ingesting real knowledge. Keep this directory access-controlled according to the institution's data classification rules.
